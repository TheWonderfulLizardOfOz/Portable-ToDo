# Portable-ToDo
A small portable to do list created using Arduino

## Why?
The aim of this project was to make the traditional to do list application but with extra constraints. I decided that the constraint would be to have it physical but on a small monochrome screen. Made for a good learning experience when dealing with a small screen and because not in a traditional environment for GUI I needed to implement features such as scrolling myself.

## Features
- Icons to display whether a task is finished or not
- LED lights are used to show task difficulty and status
- Tasks are stored persistently in an SD card
- Scrolling
- Changing task status or difficulty using buttons
